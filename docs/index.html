Runs entirely in your browser

The Python package itself is loaded and executed here via WebAssembly — there is no server, and no sequence you paste ever leaves this machine. The first run downloads the Python runtime (~12 MB, then cached); after that a design takes a few seconds.

  • Genotype — bracket a CRISPR lesion without touching it
  • qPCR — span an exon junction; graded gDNA protection
  • dCAPS — turn a 1 bp difference into a band difference
  • In situ — riboprobe template with a T7, T3 or SP6 promoter, checked for probe-level cross-hybridisation
  • Design — general-purpose, with target and exclude regions
  • Check — grade primers you already ordered

Pick a mode and press load example to see it work on the bundled mock ohnolog pair.

Not validated against bench outcomes. The algorithms are tested for correctness, but no one has yet shown these designs succeed more often than Primer3 plus manual checking. Treat the output as a well-reasoned starting point and check it.

Genome-scale off-target screening needs blastn or bowtie2 and is only available in the command-line version; in the browser, the avoid-panel is whatever you paste. For a whole-genome check, pip install danioprime.
